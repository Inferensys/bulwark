You can reach Inferensys about Bulwark in these ways:

- **Commercially licensed models:** [Contact Inferensys]({{ contact_url }}) or write to {{ contact_email }}.
- **Questions and problems:** use the Community tab of this page, or [open a GitHub issue]({{ github }}/issues).
- **Security issues:** follow [SECURITY.md]({{ code_url }}/SECURITY.md).
- **Dataset owners and removal requests:** a dataset's owners can object to this release, and people who appear in a training dataset can ask for their data to be removed. Write to {{ contact_email }}, and do not post personal data in public issues. DMD participants can also contact Vicomtech through the [DMD website](https://dmd.vicomtech.org/).

A person's removal request applies from the next retrain; weights already released are not retrained. If a dataset's owners object, the weights trained on that dataset are withdrawn and the models retrained without it (see Release basis under [Licence and dataset terms](#licence-and-dataset-terms)).
