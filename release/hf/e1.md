# Bulwark-E1: lightweight ONNX driver monitoring model for CPU (research preview)

Bulwark-E1 is a driver monitoring model in Open Neural Network Exchange (ONNX) format that runs on CPU. It was distilled from [Bulwark-B1]({{ b1_url }}) and gives {{ outputs_as_b1 }} outputs as B1, for signs of drowsiness and distraction, from a 2-second clip of a camera facing the driver.

> **E1 v0 scores well below Bulwark-B1. For research, use [Bulwark-B1]({{ b1_url }}).** E1 v0 is a research preview of a small model for CPU. Use it to try CPU and ONNX deployment and Bulwark's output format, not for its accuracy. A retrain is planned.
>
> - **Eyes closed:** it does not detect closed eyes in driver video. On DMD's test videos it scores at chance.
> - **New cameras:** on a camera view it was not trained on, its phone, eating and drinking detection falls to chance or below.
> - **Activity:** its activity results are weak.
> - **Where it works:** on close-up still images of eyes (MRL Eye), and on phone use seen from the camera views it was trained on.
>
> The scores are under [Results and speed](#results-and-speed).

## Quick start

You will download the video graph and run it on the first 2 seconds of a video, with ONNX Runtime and no Bulwark code.

1. Request access on this page. Access is granted as soon as you submit the form.
2. Install the packages and log in with a [Hugging Face access token](https://huggingface.co/settings/tokens):

   ```bash
   pip install onnxruntime numpy opencv-python-headless huggingface_hub
   hf auth login
   ```

3. Run this Python, with your own video in place of `my_clip.mp4`:

```python
import json

import cv2
import numpy as np
import onnxruntime as ort
from huggingface_hub import hf_hub_download

REPO = "{{ repo_id }}"
GRAPH = "bulwark-e1-video.onnx"  # 16 frames; bulwark-e1-image.onnx: 1 image
MEDIA = "video"  # "image" for bulwark-e1-image.onnx

graph_path = hf_hub_download(REPO, GRAPH)
with open(hf_hub_download(REPO, "config.json"), encoding="utf-8") as file:
    contract = json.load(file)["graphs"][GRAPH]["bulwark_contract"]


def letterbox(frame, size=256):
    """Keep the aspect ratio and centre on black, as Bulwark's clips are."""
    height, width = frame.shape[:2]
    scale = size / max(height, width)
    new_size = (max(1, round(width * scale)), max(1, round(height * scale)))
    method = cv2.INTER_AREA if scale < 1 else cv2.INTER_LINEAR
    resized = cv2.resize(frame, new_size, interpolation=method)
    out = np.zeros((size, size, 3), dtype=np.uint8)
    top = (size - resized.shape[0]) // 2
    left = (size - resized.shape[1]) // 2
    out[top : top + resized.shape[0], left : left + resized.shape[1]] = resized
    return out


def read_clip(path, frames=16, seconds=2.0):
    """The first 2 seconds of a video as Bulwark samples them:
    every k-th frame, letterboxed RGB."""
    video = cv2.VideoCapture(path)
    fps = video.get(cv2.CAP_PROP_FPS)
    step = max(1, max(1, round(seconds * fps)) // frames)
    clip, index = [], 0
    while len(clip) < frames:
        ok, bgr = video.read()
        if not ok:
            break
        if index % step == 0:
            clip.append(letterbox(cv2.cvtColor(bgr, cv2.COLOR_BGR2RGB)))
        index += 1
    video.release()
    # A video shorter than the clip repeats its last frame.
    clip += [clip[-1]] * (frames - len(clip))
    return np.stack(clip)[None]  # (1, frames, 256, 256, 3) uint8


def trained_outputs(contract, media):
    """The outputs trained for this media type; the others are arbitrary."""
    masked = contract.get("masked_labels", {})
    return [
        o
        for o in contract["outputs"]
        if o["name"] in contract["supervised_labels"]
        and media not in masked.get(o["name"], [])
    ]


def decode(output, logit, contract):
    """A raw logit -> probability, class probabilities or value,
    with the recorded calibration."""
    name, kind = output["name"], output["kind"]
    t = contract.get("temperature", {}).get(name, 1.0)
    if kind == "binary":
        # The threshold was tuned on the uncalibrated probability.
        threshold = contract.get("thresholds", {}).get(name, 0.5)
        return {
            "probability": float(1 / (1 + np.exp(-logit / t))),
            "flagged": bool(1 / (1 + np.exp(-logit)) >= threshold),
        }
    if kind == "categorical":
        e = np.exp((logit - logit.max()) / t)
        return dict(zip(output["classes"], (e / e.sum()).tolist()))
    low, high = output["range"]
    return float(low + (high - low) / (1 + np.exp(-logit)))


options = ort.SessionOptions()
options.intra_op_num_threads = 1  # CPU threads; 0 lets ONNX Runtime choose
session = ort.InferenceSession(
    graph_path, options, providers=["CPUExecutionProvider"]
)
outputs = trained_outputs(contract, MEDIA)
frames = read_clip("my_clip.mp4", frames=contract["input"]["shape"][1])
logits = session.run([o["name"] for o in outputs], {"frames": frames})
for output, logit in zip(outputs, logits):
    print(output["name"], decode(output, logit[0], contract))
```

- **Sampling:** a clip is 16 frames from a 2-second window, every k-th frame with `k = max(1, round(2 * fps) // 16)`. Sixteen consecutive frames of a 30 fps camera cover only half a second. For a timeline, run one call per window, for example one every second.
- **Letterbox:** `letterbox` is the resize Bulwark's training clips used. Do not stretch or crop the frames.
- **Still images:** use `bulwark-e1-image.onnx` with `MEDIA = "image"`, and pass `letterbox(rgb_image)[None, None]` as the frames. {{ copied_on_images }}
- **Output:** each trained output with its probability or value. A yes/no output also says whether it passes the decision threshold tuned on the validation people. {{ image_calibration }} Set your own thresholds on your own data.
- **config.json** holds both graphs' contracts: inputs, outputs and how to decode them, trained and withheld outputs, temperatures and thresholds. See the [ONNX contract]({{ code_url }}/docs/architecture.md#e1-onnx-contract).

Tested on 2026-11-13 in a new virtual environment with Python 3.11.13, onnxruntime 1.31.1, NumPy 2.4.6, opencv-python-headless 5.0.0 and huggingface_hub 2.4.0, on macOS on an Apple M1 Max, with the graphs downloaded from this repository.

## What it detects

For each clip, Bulwark-E1 gives one value per output below: signs of eye closure and PERCLOS (percentage of eyelid closure), yawning, head pose (yaw, pitch, roll), phone use while driving, texting, eating and drinking. The fourth column says whether a dataset's own labels (ground truth) checked the output. The last says whether the graphs were trained for it on video, on still images or both. "Copies B1 only" marks a media type on which no training clip had a label for the output: there, E1 only learned to copy Bulwark-B1's output, which B1 learned from the other media type.

{{ labels_table }}

Notes on some outputs:

- **PERCLOS** is here the share of the clip's frames with the eyes closed. Drowsiness research averages it over 60 seconds or more, so average it over consecutive clips.
- **Eye openness** was checked on MRL Eye's still images only.
- **Head yaw, pitch and roll** are returned divided by 90, from -1 to 1. Multiply by 90 for degrees. Pitch is positive when the head tips down relative to the camera, so 0 means facing the camera, not a level head. Yaw is positive when the person turns to their own left.
- **Head nod:** do not use it in v0. Its training labels came from a rule that had the pitch sign the wrong way round, so it fired when the head rose and came back rather than on a nod. The sign error is fixed in the code for the next model, but the rule still cannot tell nodding off from looking down, and no ground truth has checked it.
- **Activity** is one of: attentive, looking away, phone call, texting, eating, drinking, talking, reaching, grooming, adjusting controls, reading, interacting with an object, or other. The model file also has classes that were never trained (below).
- **Camera type** (RGB colour or near-infrared) and **low light** describe the recording, not the driver, so the evaluation uses them only as sanity checks.

The graphs also have outputs that were not trained: {{ untrained_outputs }}. They return arbitrary values; the quick start leaves them out, and also leaves out the outputs not trained for the graph's media type. {{ untrained_classes }}

## Intended use, out-of-scope uses and limitations

This section says what Bulwark-E1 is for, what it must not be used for, and where it falls short.

### Intended use

E1 v0 is for trying Bulwark on a CPU, not for its accuracy:

- Trying a driver monitoring model on CPU with ONNX Runtime: the files, the speed and Bulwark's output format.
- Experiments with a small base model: its 256-number state embedding can train small task adapters for labels of your own.

For research on driver drowsiness and distraction, use [Bulwark-B1]({{ b1_url }}).

It is for researchers, in academic and other non-commercial research.

Fleet operators, video telematics and AI dash cam providers, car makers (automotive OEMs) and their Tier-1 suppliers, and safety teams in industry need a commercially licensed model from Inferensys for product work, pilots and evaluations, as does any other commercial use. See [Commercial models](#commercial-models).

### Limitations

E1 learned from Bulwark-B1 and the same datasets, so it shares B1's limitations, which [Bulwark-B1's card]({{ b1_url }}#limitations) explains:

- **Few people:** Drive&Act, DMD and MRL Eye have 14 to 37 people each, and each test set holds only 3 of them.
- **No results by group:** no video dataset records age, sex or skin tone.
- **Narrow conditions:** mostly cars and near-infrared video, with no thermal cameras. Not tested in trucks, buses, forklifts, mining or heavy-equipment cabins.
- **Short clips:** each clip covers 1 to 2 seconds, while drowsiness develops over minutes.
- **Head pose, mouth open and head nod:** learned from a face model's labels only, and not checked. The head nod labels were wrong (see the notes on outputs): ignore that output.
- **Blink and yawn:** learned from one camera of one dataset (DMD).
- **New camera positions:** on a camera position that training never used, B1's scores were lower, and E1's fell to chance or below. In research, check it on your own cameras.
- **Not calibrated for real settings:** research on other data needs thresholds set on that data.
- **Untrained outputs:** the outputs listed as not trained under [What it detects](#what-it-detects) return arbitrary values.

E1 also has its own:

- **Accuracy:** E1 v0 scores well below B1 on most outputs. It does not detect closed eyes in driver video, and its blink, yawn and activity results are weak. See [Results and speed](#results-and-speed).
- **New people:** it scores much better on the people it was trained on than on new people.
- **Learned from B1:** E1 learned to copy B1's outputs on every training clip, so B1's errors carry over.
- **Precision:** the graphs use 32-bit floats. No quantized version exists yet.
- **Speed varies:** CPU speed depends on the machine, its load and the number of threads.
- **Image graph:** it sees one frame, so it has no motion and cannot time blinks, yawns or head nods. {{ copied_on_images }} {{ not_trained_on_images }}

## How it was made

Bulwark-E1 starts from timm's EfficientViT-B1 image model, pretrained on ImageNet-1k. Inferensys trained it on the datasets' own labels and on Bulwark-B1's outputs, a method called knowledge distillation. It was then exported to ONNX and checked against the PyTorch model.

This first E1, E1 v0, did not reach B1's accuracy. Inferensys released it as a research preview, to try on CPU, and plans to retrain E1 with a different recipe.

<details>
<summary>Architecture and export details, for researchers</summary>

- **Backbone:** EfficientViT-B1 ([EfficientViT paper](https://arxiv.org/abs/2205.14756)) applied to each frame at 224 x 224 pixels. The graph resizes the 256 x 256 input and applies the ImageNet normalisation itself.
- **Head:** a 2-layer transformer over the per-frame features. The state embedding has 256 values.
- **Training:** the datasets' labels and the face model's labels, as for B1, plus Bulwark-B1's outputs on the same clips as soft targets ([knowledge distillation](https://arxiv.org/abs/1503.02531)). E1 copies B1 only on the outputs B1 was trained on.
- **Export:** ONNX opset 17, with the time axis fixed at export: 16 frames for the video graph, 1 for the image graph. The batch size is free.
- **Parity:** {{ parity }} Each graph records the check. Over every evaluation clip, the video graph's label logits differ from the PyTorch model's by at most 2.3e-03, above that tolerance, and the image graph's by at most 2.6e-04. On every clip, each yes/no output is on the same side of 0.5 and the top activity class is the same, and the test and holdout scores differ by at most 6.2e-06. See [E1 v0 test results]({{ code_url }}/docs/evaluation.md#e1-v0-test-results).
- **Metadata:** each graph stores its contract as `bulwark_contract`, with the licence (`license`), this card's address (`model_card`), the trained and withheld outputs (`supervised_labels`, `masked_labels`), and the temperatures and thresholds of its media type.
- **Parameters:** {{ parameters_exact }} values in the video graph's weights.
- More in [Architecture: Bulwark-E1]({{ code_url }}/docs/architecture.md#bulwark-e1) and [Training: E1 distillation]({{ code_url }}/docs/training.md#4-e1-distillation).

</details>
